# JavaScript Testing Guide

## Обзор

Тестирование JavaScript кода для `home.js` настроено с использованием Jest.

## Установка зависимостей

```bash
npm install
```

## Запуск тестов

### Запустить все тесты
```bash
npm test
```

### Запустить тесты с покрытием
```bash
npm run test:coverage
```

### Запустить тесты в watch режиме
```bash
npm run test:watch
```

### Запустить тесты с подробным выводом
```bash
npm run test:verbose
```

## Структура тестов

Тесты находятся в: `OpenRouterChats/Chats/static/Chats/tests/home.test.js`

### Покрытие функций

1. **getCSRFToken()** - Извлечение CSRF токена из cookies
   - Извлечение токена из cookie
   - Обработка отсутствующего токена
   - Декодирование URI
   - Работа с несколькими cookies
   - Обработка специальных символов

2. **getChatHistory()** - Чтение истории из localStorage
   - Возврат пустого массива при отсутствии истории
   - Парсинг истории из localStorage
   - Обработка пустой истории
   - Обработка null значений

3. **saveChatHistory()** - Сохранение истории в localStorage
   - Сохранение истории
   - Сохранение пустого массива
   - Перезапись существующей истории
   - Обработка множественных сообщений

4. **fillChatHistory()** - Рендеринг сообщений в DOM
   - Отображение "нет сообщений"
   - Рендеринг пользовательских сообщений
   - Рендеринг сообщений ассистента
   - Рендеринг множественных сообщений
   - Очистка предыдущих сообщений
   - Экранирование HTML
   - Автоматическая прокрутка

5. **fillModelsSelector()** - Заполнение селектора моделей
   - Заполнение select моделями
   - Добавление placeholder
   - Восстановление выбранной модели
   - Очистка существующих опций
   - Обработка пустого массива
   - Обработка невалидного JSON

6. **fillTeachersSelector()** - Заполнение селектора учителей
   - Заполнение select учителями
   - Добавление placeholder
   - Восстановление выбранного учителя
   - Пропуск учителей без id
   - Использование id как текста при отсутствии имени
   - Обработка пустого массива
   - Конвертация числовых id в строки

7. **checkBeforeSend()** - Валидация перед отправкой
   - Проверка выбора модели
   - Проверка выбора учителя
   - Проверка пустого сообщения
   - Проверка сообщения из пробелов
   - Валидация всех полей
   - Добавление/удаление класса is-invalid
   - Таймауты для UI индикаторов

## Конфигурация

### package.json
- Jest настроен с `jsdom` окружением для тестирования DOM
- Минимальное покрытие: 80% (branches, functions, lines, statements)
- Тесты находятся в `**/tests/**/*.test.js`

### jest.setup.js
- Моки для localStorage
- Моки для Bootstrap компонентов (Modal, Tooltip, Toast)
- Настройка document.cookie

## Требования к покрытию

Минимальное покрытие установлено на 80% для:
- Ветвлений (branches)
- Функций (functions)
- Строк (lines)
- Выражений (statements)

## Зависимости

- `jest`: Тестовый фреймворк
- `jest-environment-jsdom`: DOM окружение для Jest
- `jest-localstorage-mock`: Мок для localStorage
- `@testing-library/jest-dom`: Дополнительные матчеры для DOM
- `@testing-library/dom`: Утилиты для тестирования DOM

## Примечания

- Все функции извлекаются из home.js через Function constructor для изоляции
- Bootstrap компоненты замоканы в jest.setup.js
- localStorage автоматически очищается перед каждым тестом
- Используется jsdom для симуляции браузерного окружения
